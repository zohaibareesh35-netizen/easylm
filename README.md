# easylm

Large language models (LLMs) made easy, EasyLM is a one stop solution for pre-training, finetuning, evaluating and serving LLMs in JAX/Flax.

## Features

- written in Python
- simple installation from releases
- open source

## Installation

Download a release or build from source (Python).

## Usage

```
easylm --help
```
